# Приложение Битрикса: установка, токены, регистрация бота. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ава появляется в портале как чат-бот и отвечает сотрудникам от своего имени.

**Architecture:** Портал ставит локальное приложение и присылает на `/bitrix/` событие установки с токенами. Токены хранятся на диске рядом с конфигом и обновляются по истечении часа. Ими же выполняется регистрация бота и отправка сообщений — вебхук для отправки больше не годится, потому что бот принадлежит приложению.

**Tech Stack:** Node 22, TypeScript, vitest.

## Global Constraints

- Токены — секрет. Права файла 600, в журнал и в тексты ошибок не попадают. Ни `access_token`, ни `refresh_token`, ни `client_secret`.
- Умолчание — запрет: нет токенов → канал не поднимается и честно об этом пишет, а не работает наполовину.
- `src/core/*` не импортирует `src/channels/*`.
- Тесты в `test/`, зеркалят `src/`, импорты с `.js`.
- Код и комментарии по-английски, тексты для людей по-русски.
- База: **973 passed | 84 skipped | 0 failed**, typecheck 0.
- Каждая задача: тест → падение → код → зелёное → коммит.

**Interfaces:**

  - `class BitrixTokenStore { constructor(filePath: string); load(): BitrixTokens | null; save(t: BitrixTokens): void; isExpired(t: BitrixTokens, now?: number): boolean }`

- [ ] **Step 1: Написать падающий тест**

Создать `test/channels/bitrix-tokens.test.ts`. Проверить:

4. Права файла после записи — `600` (на Windows проверку прав пропустить: `process.platform === "win32"` → тест помечается как пройденный, но сам факт записи проверяется).
5. `isExpired` считает токен просроченным за минуту ДО формального истечения — запас на дорогу запроса.

Run: `npm run test -- test/channels/bitrix-tokens.test.ts`

- [ ] **Step 3: Реализовать**

Ключевое в реализации:

- запись атомарная: сначала во временный файл рядом, потом переименование. Иначе обрыв посреди записи оставит битый файл и Ава не поднимется;
- `chmod 600` сразу после создания, до записи содержимого;
- при чтении любые ошибки (нет файла, не JSON, не те поля) → `null` с записью причины в журнал БЕЗ содержимого файла;
- `isExpired(t, now = Date.now())` → `now >= t.expiresAt - 60_000`.
